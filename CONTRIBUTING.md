# Contributing

Changes to JianboTV are distributed under GPL-3.0. Keep user data, private playlist URLs, credentials, signing keys, and machine-local configuration out of commits and issue attachments.

Before proposing a change, run the relevant Gradle checks from the repository root. For updater changes, verify the fixed repository, versionCode metadata, exact release asset naming, HTTPS redirect allowlist, SHA-256 validation, APK package/version/signature checks, cancellation, and Android system installer handoff.
